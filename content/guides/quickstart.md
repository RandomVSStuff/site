# First Steps

You got onto the server, now what? You have a couple of options, you can join someone's town, or start your own journey. When you join you will be spawned in a 5km radius of the spawn point in a temperate biome. If you decide to start your own journey, you can approach this a few different ways:

`/rtp` teleports you within a 5km radius of your current position, you must wait 60 seconds before using the command again

`/t2p` a very high cooldown command that allows you to teleport to another player

Or you can just walk! This may make take some time though, but it will get you the most lay of the land.

# Once you settle

You may quickly notice there is no map, this is because maps must be crafted, information on how to craft them can be found in the handbook. One of the first things you may want to do is create a land claim, in order to do this, you will need to farm, see [[farming]] for a guide on how to get started. Once you have collected enough food, you can then start yourself a new [[claim]]. Another thing to note is going to be the changes to [[animal-breeding]].
