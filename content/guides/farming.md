# Principal Changes

Farming on this server differs from vanilla in a few key ways:
- Extended Growth Time
- Generational Breeding
- Weeds
- Berry Vernalization

Each of these changes will change how you approach creating a sustainable food chain within the server.

# Generational Breeding

Crops will now work with generations, the higher the generation, the better yield the crop produces. So keeping plants alive becomes a priority if you want to create a more sustainable farming practice.

# Weeds

Weeds can be introduced and kill crops if you aren't careful, you can decrease the chance of your crops getting weeds by mulching them with dry grass

# Berry Vernalization

No more just picking a bush off the ground and taking it home as if it was a fully mature one! Berry bushes must wait until the next summer before they produce more.
